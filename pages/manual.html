Manual técnico y de usuario

1. Manual técnico

  • Tecnologías: HTML5, CSS3, Bootstrap 5.0.2 (CDN), Bootstrap Icons, Font Awesome 6.
  • Editor: Visual Studio Code con la extensión Live Server (puerto 5501).
  • Control de versiones: Git y GitHub. Hosting: GitHub Pages.

2. Manual de usuario

  1. Navegar: use el menú superior para ir a Inicio, Productos, Multimedia, Manual y Contacto.
  2. Ver productos: en Productos encuentra el catálogo con precios y una tabla comparativa.
  3. Crear cuenta: Tu cuenta → Registro. Complete el formulario y acepte los términos.
  4. Iniciar sesión: Tu cuenta → Iniciar sesión con correo y contraseña.
  5. Contactar: en Inicio, sección Contáctenos, envíe su mensaje.
